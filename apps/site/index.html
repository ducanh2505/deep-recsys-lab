One continuous workflow

From raw events to a stable API.

Each stage has an explicit contract, so experiments can evolve without turning production into an archaeology project.

01
⌁

Prepare

Normalize generic interaction tables, validate IDs, and create reproducible mappings and splits.

recsys data prepare
02
◇

Train

Select a model plugin and override typed configuration without changing orchestration code.

recsys train model=multivae
03
∿

Evaluate

Measure ranking quality against the configured split and retain run-local provenance.

recsys evaluate
04
↗

Serve

Load a verified artifact through a framework-neutral engine and expose a consistent contract.

recsys serve --artifact …

Built-in building blocks

Useful defaults.
Replaceable boundaries.

Start with familiar recommendation techniques, then compose only the components your product needs.

Models

Collaborative, graph, sequential, and embedding-based

MultiVAE, LightGCN, BPR, SASRec, and two-tower implementations share a common lifecycle.

Retrieval

Classical signals and learned representations

Popularity, nearest neighbours, text similarity, transitions, graph signals, and trained models plug into one registry.

Fusion

Compose candidates without hard-coded ensembles

Reciprocal-rank, weighted, and learned fusion strategies read their component list directly from configuration.

Runtime

Known-user and session-history recommendations

Artifacts declare supported query modes, runtime requirements, checksums, and catalog metadata.

Designed for extension

Add a capability without rewriting the platform.

Registries turn models, retrievers, fusion strategies, rerankers, and runtimes into explicit extension points. Implement the contract, register the plugin, and select it through configuration.

Local quickstart

A clean workspace in four commands.

Install the project, inspect available plugins, run a synthetic pipeline, and query the resulting artifact.

uv sync --extra cpu --extra train --extra serve
uv run recsys plugins list
uv run recsys run dataset=synthetic model=multivae
uv run recsys serve --artifact var/models/multivae/<digest>
